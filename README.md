## 수정 방법
1. 이 화면에서 **Add file → Upload files**
2. 고친 html 파일을 끌어다 놓기 (같은 이름이면 자동으로 덮어쓰기)
3. **Commit changes** → 1~2분 뒤 반영

파일 이름을 바꾸지 않는 한 위 주소는 바뀌지 않습니다.
